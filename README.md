# WakePeek

**Что разбудило ПК.** Когда машина уснула, когда проснулась, и что Windows записала как источник: кнопка, устройство, таймер. Если причины нет — так и пишет.

**Автор:** darkshade ([@vlx0](https://github.com/vlx0))

**365 дней open source** · **неделя 10 — «Следы»** · день 65.

Не BootPeek: там включения и выключения. Здесь сон и пробуждение.

---

## Возможности

- список сессий: сон → пробуждение, сколько проспала
- источник: кнопка питания, устройство, таймер — если Windows это записала
- сон, гибернация или гибридный сон
- почему уснула, если в журнале есть запись (например простои)
- период 7 / 14 / 30 / 90 дней
- только журнал System, без журнала Security и без прав администратора

## Установка

```powershell
git clone https://github.com/vlx0/WakePeek.git
cd WakePeek
pythonw run_wakepeek.pyw
```

Или `start.bat`.

Нужен Windows 10+ и Python 3.10+. Внешних зависимостей нет.
